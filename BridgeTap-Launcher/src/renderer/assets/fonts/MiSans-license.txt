This program bundles the variable (VF) web build of MiSans, split into 56 woff2
shards along the unicode ranges published by Xiaomi's official font service, stored
under assets/fonts/misans/. It is packaged with the application and rendered inside
this program's own UI only; no glyph was modified in any way.

本程序内置 MiSans 的可变字体（VF）网页版本，按小米官方字体服务的 unicode
区间切分为 56 个 woff2 分片，存放于 assets/fonts/misans/。使用方式为随程序
打包、在本程序界面内渲染，未对字体文件做任何字形改造。
